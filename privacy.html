隐私政策

最后更新日期：2025年1月1日

1. 信息收集

全能工具箱（以下简称"本站"）非常重视用户隐私。本站是一个纯静态网站，不会主动收集、存储或传输您的个人信息。

本站可能收集的信息包括：

  • 浏览器本地存储：用于保存主题偏好、收藏夹、最近使用等功能数据，这些数据仅存储在您的浏览器中
  • 匿名统计数据：通过 Google Analytics 收集的匿名访问统计，如页面浏览量、访问来源等

2. Cookie 使用

本站使用 Cookie 来改善用户体验：

  • 功能性 Cookie：用于记住您的主题偏好（深色/浅色模式）
  • 分析 Cookie：Google Analytics 使用的 Cookie，用于收集匿名统计数据
  • 广告 Cookie：Google AdSense 可能使用 Cookie 来展示相关广告

3. 第三方服务

本站使用以下第三方服务：

  • Google Analytics：用于分析网站流量和使用情况。Google 隐私政策
  • Google AdSense：用于展示广告。Google 广告政策
  • GitHub Pages：用于托管本网站。GitHub 隐私声明

4. 数据安全

本站所有数据传输均通过 HTTPS 加密。您在本站使用的工具（如计算器、转换器等）所输入的数据仅在您的浏览器中处理，不会上传到任何服务器。

5. 用户权利

您可以：

  • 清除浏览器中的 Cookie 和本地存储数据
  • 使用浏览器的"请勿跟踪"功能
  • 使用广告拦截器阻止广告

6. 儿童隐私

本站不会故意收集 13 岁以下儿童的个人信息。如果您是家长或监护人，发现您的孩子向我们提供了个人信息，请联系我们删除。

7. 隐私政策更新

本站可能会不时更新本隐私政策。更新后的政策将在本页面发布，并更新"最后更新日期"。

8. 联系我们

如果您对本隐私政策有任何疑问，请通过以下方式联系我们：

  • GitHub Issues：提交问题
